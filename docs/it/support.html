Assistenza

Attivare la tastiera

  1. Android: Impostazioni → Sistema → Tastiera → Gestisci tastiere → attiva The Pill. Poi sceglila nel selettore delle tastiere.
  2. iPhone: Impostazioni → Generali → Tastiera → Tastiere → Aggiungi nuova tastiera → The Pill → attiva «Consenti accesso completo» (senza, la tastiera non può chiamare il server).
  3. Nell’app The Pill inserisci l’indirizzo del server e lascia attivi i suggerimenti.

Il suggerimento non compare

Il suggerimento arriva dopo una breve pausa nei messaggi di oltre 12 caratteri. Non compare mai nei campi password. Se il server non risponde, la tastiera tace e scrivi normalmente.
