支持

启用键盘

  1. Android：设置 → 系统 → 键盘 → 管理键盘 → 开启 The Pill，然后在键盘切换器中选择它。
  2. iPhone：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → The Pill → 开启“允许完全访问”（否则键盘无法调用服务器）。
  3. 在 The Pill 应用中填写服务器地址，并保持建议开启。

建议没有出现

对于超过 12 个字符的消息，稍作停顿后会出现建议。在密码输入框中永远不会出现。服务器无响应时，键盘保持沉默，你照常输入即可。
