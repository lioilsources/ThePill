કીબોર્ડ ચાલુ કરવું

  1. Android: સેટિંગ્સ → સિસ્ટમ → કીબોર્ડ → કીબોર્ડ મેનેજ કરો → The Pill ચાલુ કરો. પછી કીબોર્ડ સ્વિચરમાંથી તેને પસંદ કરો.
  2. iPhone: સેટિંગ્સ → સામાન્ય → કીબોર્ડ → કીબોર્ડ → નવું ઉમેરો → The Pill → «સંપૂર્ણ ઍક્સેસ મંજૂર કરો» ચાલુ કરો (તેના વિના કીબોર્ડ સર્વરને બોલાવી શકતું નથી).
  3. The Pill ઍપમાં સર્વરનું સરનામું આપો અને સૂચનો ચાલુ રાખો.

સૂચન દેખાતું નથી

12 અક્ષરથી લાંબા સંદેશમાં થોડા વિરામ પછી સૂચન આવે છે. પાસવર્ડના ખાનામાં તે ક્યારેય દેખાતું નથી. સર્વર જવાબ ન આપે તો કીબોર્ડ ચૂપ રહે છે અને તમે સામાન્ય રીતે લખો છો.
