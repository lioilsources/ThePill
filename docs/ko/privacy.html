개인정보 처리방침

최종 업데이트: 2026년 11월 8일

Oldřich Vořechovský(ol1n)의 The Pill(com.ol1n.thePill)은 입력 중인 메시지를 더 차분하게 표현하도록 제안하는 키보드예요. 계정, 광고, 분석, 추적이 없어요.

  • 전송되는 것: 메시지가 12자 이상이면 키보드가 잠시 멈춘 뒤 초안을 앱에 설정된 pill-core 서버로 보내요. 제안을 탭할 때만 글이 바뀌어요.
  • 비밀번호 등 민감한 입력란에서는, 제안이 꺼져 있거나 서버가 설정되지 않았을 때는 아무것도 보내지 않아요.
  • 처리 위치: 언어 모델은 운영자 자신의 하드웨어에서 실행되며, 외부 AI 서비스가 아니에요. pill-core는 메시지 글을 저장하거나 기록하지 않고, 내용이 없는 운영 데이터만 남겨요.
  • 기기 안: 서버 주소, 액세스 토큰, 제안 스위치는 내 휴대폰에만 저장돼요.
