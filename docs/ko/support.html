키보드 켜기

  1. Android: 설정 → 시스템 → 키보드 → 키보드 관리 → The Pill을 켜세요. 그다음 키보드 전환에서 선택하세요.
  2. iPhone: 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → The Pill → 「전체 접근 허용」을 켜세요(켜지 않으면 키보드가 서버를 호출할 수 없어요).
  3. The Pill 앱에서 서버 주소를 입력하고 제안을 켜 두세요.

제안이 나타나지 않아요

제안은 12자가 넘는 메시지에서 잠시 멈춘 뒤에 나타나요. 비밀번호 입력란에는 절대 나타나지 않아요. 서버가 응답하지 않으면 키보드는 조용히 있고, 평소처럼 입력하면 돼요.
