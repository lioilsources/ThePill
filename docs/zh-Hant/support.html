啟用鍵盤

  1. Android：設定 → 系統 → 鍵盤 → 管理鍵盤 → 開啟 The Pill，然後在鍵盤切換器中選擇它。
  2. iPhone：設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤 → The Pill → 開啟「允許完整取用」（否則鍵盤無法呼叫伺服器）。
  3. 在 The Pill App 中填寫伺服器位址，並保持建議開啟。

建議沒有出現

對於超過 12 個字元的訊息，稍作停頓後會出現建議。在密碼欄位中絕不會出現。伺服器沒有回應時，鍵盤保持沉默，你照常輸入即可。
