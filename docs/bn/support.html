কিবোর্ড চালু করা

  1. অ্যান্ড্রয়েড: সেটিংস → সিস্টেম → কিবোর্ড → কিবোর্ড পরিচালনা → The Pill চালু করো। তারপর কিবোর্ড বদলানোর মেনু থেকে বেছে নাও।
  2. আইফোন: সেটিংস → সাধারণ → কিবোর্ড → কিবোর্ডসমূহ → নতুন যোগ → The Pill → «পূর্ণ অ্যাক্সেস অনুমতি দিন» চালু করো (এটা ছাড়া কিবোর্ড সার্ভারে যেতে পারে না)।
  3. The Pill অ্যাপে সার্ভারের ঠিকানা দাও এবং পরামর্শ চালু রাখো।

পরামর্শ আসছে না
