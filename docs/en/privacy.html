Privacy Policy

Last updated: November 8, 2026

The Pill (com.ol1n.thePill) by Oldřich Vořechovský (ol1n) is a keyboard that suggests a calmer wording for the message you are typing. It has no account, ads, analytics or tracking.

  • What is sent: when a message has at least 12 characters, the keyboard sends the draft, after a short pause, to the pill-core server configured in the app. The text is replaced only if you tap the suggestion.
  • Never sent from password or other sensitive fields, or when suggestions are off or no server is set.
  • Where: the language model runs on the operator's own hardware, not a third-party AI service. pill-core does not store or log message text, only content-free operational data.
  • On device: the server address, access token and the suggestions toggle are stored only on your phone.
