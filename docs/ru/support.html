Поддержка

Включение клавиатуры

  1. Android: Настройки → Система → Клавиатура → Управление клавиатурами → включите The Pill. Затем выберите её в переключателе клавиатур.
  2. iPhone: Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры → The Pill → включите «Разрешить полный доступ» (без него клавиатура не сможет обращаться к серверу).
  3. В приложении The Pill укажите адрес сервера и оставьте подсказки включёнными.

Подсказка не появляется

Подсказка появляется после короткой паузы для сообщений длиннее 12 символов. В полях для паролей она не появляется никогда. Если сервер не отвечает, клавиатура молчит, и вы печатаете как обычно.
