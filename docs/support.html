Zapnutí klávesnice

  1. Android: Nastavení → Systém → Klávesnice → Spravovat klávesnice → zapni The Pill. Pak ji vyber v přepínači klávesnic.
  2. iPhone: Nastavení → Obecné → Klávesnice → Klávesnice → Přidat → The Pill → zapni Povolit plný přístup (bez něj klávesnice nemůže volat server).
  3. V appce The Pill zadej adresu serveru a nech napovídání zapnuté.

Návrh se neobjevuje

Návrh přijde po krátké pauze u zpráv delších než 12 znaků. V polích pro hesla se nezobrazuje nikdy. Když server neodpovídá, klávesnice mlčí a píše dál normálně.

Kontakt

Chybu nebo nápad pošli na business@olin.now.

English: enable the keyboard in system settings (on iPhone also allow Full Access), set the server address in the app. Suggestions appear after a short pause for messages over 12 characters, never in password fields. Contact: business@olin.now.
