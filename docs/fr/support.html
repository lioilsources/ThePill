Assistance

Activer le clavier

  1. Android : Paramètres → Système → Clavier → Gérer les claviers → active The Pill. Puis choisis-le dans le sélecteur de claviers.
  2. iPhone : Réglages → Général → Clavier → Claviers → Ajouter → The Pill → active « Autoriser l’accès complet » (sans cela, le clavier ne peut pas appeler le serveur).
  3. Dans l’appli The Pill, saisis l’adresse du serveur et laisse les suggestions activées.

La suggestion n’apparaît pas

La suggestion arrive après une courte pause pour les messages de plus de 12 caractères. Elle n’apparaît jamais dans les champs de mot de passe. Si le serveur ne répond pas, le clavier reste muet et tu écris normalement.
