Support

Tastatur aktivieren

  1. Android: Einstellungen → System → Tastatur → Tastaturen verwalten → The Pill einschalten. Dann im Tastaturumschalter auswählen.
  2. iPhone: Einstellungen → Allgemein → Tastatur → Tastaturen → Neue Tastatur → The Pill → „Vollen Zugriff erlauben“ einschalten (ohne ihn kann die Tastatur den Server nicht erreichen).
  3. In der App The Pill die Serveradresse eintragen und die Vorschläge eingeschaltet lassen.

Der Vorschlag erscheint nicht

Der Vorschlag kommt nach einer kurzen Pause bei Nachrichten mit mehr als 12 Zeichen. In Passwortfeldern erscheint er nie. Antwortet der Server nicht, schweigt die Tastatur und du schreibst ganz normal weiter.
